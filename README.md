# 둥지 테니스 기록

둥지 테니스 클럽 경기 결과를 입력하면 복식 기준 개인 순위, 복식 조합 순위, 선수별 전적을 계산해 주는 웹 앱입니다.

- 데이터: Supabase (프로젝트 `둥지 테니스 기록`, 서울 리전)
- 휴대폰: 사파리 '홈 화면에 추가' / 크롬 '앱 설치'
- 규칙: 6게임 선승, 5:5는 무승부 (설정에서 변경 가능)
- 회원(로그인 없음): 경기·선수 추가, 입력 후 24시간 안의 경기만 휴지통으로
- 관리자(설정 탭에서 로그인): 지난 기록 삭제·되살리기, 선수 수정, 설정, 가져오기
- 관리자 등록: Supabase `admins` 테이블에 계정 user_id 추가 (`supabase/03-admin.sql` 참고)
- 대회: 관리자가 날짜를 대회로 지정하면 그날 경기는 대회 탭에서 따로 시상(개인·조합 1~3위)하고 평소 통계에서 제외
- 삭제한 경기는 휴지통에서 되살릴 수 있음

`app.js`의 키는 브라우저용 공개(publishable) 키이며, 테이블은 RLS로 보호됩니다. 비밀(secret) 키는 이 저장소에 넣지 마세요.
