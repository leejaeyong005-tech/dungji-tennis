# 둥지 테니스 기록

둥지 테니스 클럽 경기 결과를 입력하면 복식 기준 개인 순위, 복식 조합 순위, 선수별 전적을 계산해 주는 웹 앱입니다.

- 데이터: Supabase (프로젝트 `둥지 테니스 기록`, 서울 리전)
- 휴대폰: 사파리 '홈 화면에 추가' / 크롬 '앱 설치'
- 규칙: 6게임 선승, 5:5는 무승부 (설정에서 변경 가능)
- 회원(로그인 없음): 경기·선수 추가. 등록한 날과 그다음 날까지(한국 시간)는 누구나 경기·선수 수정/휴지통 가능 (`supabase/06-edit-window.sql`)
- 관리자(설정 탭에서 로그인): 기한이 지난 기록 수정·삭제·되살리기, 선수 수정, 설정, 가져오기
- 관리자 등록: Supabase `admins` 테이블에 계정 user_id 추가 (`supabase/03-admin.sql` 참고)
- 대회: 관리자가 날짜를 대회로 지정하면 그날 경기는 대회 탭에서 따로 시상(개인·조합 1~3위)하고 평소 통계에서 제외
- 기수: 관리자가 설정 탭에서 이름·시작일·종료일 등록 및 언제든 수정 (분기/반기/연 단위 자동 제안). 순위 기간에서 기수 선택, 기수별 1~3위와 선수별 기수 성적 표시
- 삭제한 경기는 휴지통에서 되살릴 수 있음. 휴지통 완전 삭제/비우기는 수정 기한(등록 당일+다음 날) 안이면 누구나, 이후 관리자만. 휴지통 30일 경과 시 매일 새벽 4시 자동 삭제 (`supabase/07-purge.sql`, pg_cron)

`app.js`의 키는 브라우저용 공개(publishable) 키이며, 테이블은 RLS로 보호됩니다. 비밀(secret) 키는 이 저장소에 넣지 마세요.
